# 识图美术资源目录约定

本文记录自动编队、羁绊补齐和个人库存构建所使用的主要卡面资源。新增识图逻辑时应按 UI 场景选目录，不能仅因对象 ID 相同而混用模板。

| 路径 | UI 场景 | 当前使用方 | 约定 |
| --- | --- | --- | --- |
| `assets/resource/base/image/NarrowFigures/` | 从者选择列表中的窄头像 | 自动编队、羁绊补齐查找从者；现有编队槽位代码也优先使用 | 列表用途明确；编队页通用识别沿用现有代码作为待标定基线，不代表已证明全库适配 |
| `assets/resource/base/image/servant_face/` | 从者完整头像/灵基一览卡面 | 当前编队识别缺少窄头像时的备用、个人从者库扫描 | 通用编队评估可单独选择此目录进行对照；个人库存扫描只在内存中截取稳定区域，不改原图 |
| `assets/resource/base/image/EquipFaces/list/` | 礼装选择列表及灵基一览礼装卡面 | 自动编队、羁绊补齐查找礼装、个人礼装库扫描 | 这是礼装列表匹配模板；模板已经裁好，按原图匹配，不使用 `team` 代替 |
| `assets/resource/base/image/EquipFaces/team/` | 编队页面的礼装槽位 | 自动编队、羁绊补齐落地复核 | 只用于编队槽位匹配；不用于仓库/选择列表查找 |
| `assets/resource/base/image/个人库存/稀有度/` | 灵基一览小图标卡片上的星级条 | 仅“构建个人从者礼装库”行列定位 | 解包图经纯黑转绿幕、0.74 倍 Bilinear 缩放生成；不能作为身份模板，也不能替代其他任务的星级素材 |
| `assets/resource/base/image/EquipFaces/礼装类别筛选项/` | 礼装筛选页的类别选项 | 羁绊补齐礼装筛选 | 与具体礼装卡面模板无关 |
| `assets/resource/base/image/lizhuang/` | 助战识别使用的命名礼装模板 | 助战信息识别 | 属于助战流程的既有资源，不替代 `EquipFaces/list` 或 `EquipFaces/team` |

## 个人库存扫描的坐标约定

- 灵基一览的从者与礼装扫描都固定使用“小图标”布局，但只限“构建个人从者礼装库”任务；其他任务保留各自图标尺寸。
- `servant_face` 与 `EquipFaces/list` 原文件保持不变；库存代码在内存中按小图标比例 Bilinear 缩放后匹配。
- Atlas 的 `collectionNo=0` 内部变体或跨 ID 灵衣 face 必须合并进其正式可持有从者的 `images`，不能作为个人库存的独立身份候选；例如芙萝拉关联 `f_1002100*`、玛修关联 `f_8002100.png`、普勒拉蒂关联内部变体灵衣 `f_5057300.png`。个人库存构建只枚举 `collection_no` 非空的正式图鉴条目，运行目录仍可保留内部变体供其他任务兼容。
- 1280×720 实机下，小图标卡片左缘为 `83、223、362、502、642、781、921、1061`，纵向行距约 149px。首排 Y 不固定，由稀有度单星模板与整页网格约束逐屏求相位。坐标会随设备分辨率按现有基准缩放。
- 礼装缩放模板约为 110×42，预期左上角为“卡片左缘 +11、卡片上缘 +24”；最终匹配允许 ±5px 浮动。
- 资源目录表达的是模板适用的 UI 场景；若界面布局发生变化，应调整截图 ROI 或布局坐标，不能修改原模板来掩盖坐标问题。

## 通用编队身份识别（2026-09-12）

- 当前源码的 `_prepare_target_templates` 确实优先加载 `NarrowFigures`，缺失时再用 `servant_face`；此前表格“编队槽位不使用窄头像”的绝对描述与源码不一致，已修正为待标定范围。
- 新采集器复用该优先顺序和匹配方法；也支持离线单独评估 `servant_face`，不改写任何原图。
- 候选索引先使用 `servant_list.json.images`，再按既有 `svtId[:-2] + 三位变体号 + 可选 d` 命名补充。冲突或无法映射的图片排除并报告，不按名称猜测 ID。
- 当前索引覆盖 472 个目录 ID；`1700100`、`9935530` 通过完整头像备用目录覆盖。这是文件覆盖证据，不是编队页识别准确率。
- `强化从者/职介-*` 是筛选页模板，未用作编队职阶图标。需要真实编队页素材、槽位内 ROI 和分差标定后才能启用职阶剪枝。
- 详细状态、测试及采集限制见 [通用编队身份识别](通用编队身份识别.md)。
