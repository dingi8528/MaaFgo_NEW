## 已实施修改

| 项目 | 修改 | 效果与边界 |
| --- | --- | --- |
| F1 结算分支被遮挡 | 将 DirectHit 推进放到候选末尾，补入撤退、撤退确认、剧情跳过和连续场补体力；每个盲点节点最多命中 150 次，每场重置计数 | 明确画面优先走对应分支；未知画面有界失败。节点 `timeout=10000` 是框架查找超时，不是整个结算总时长 |
| F2 最终场误入续战 | 拆分最终场和连续场的好友申请节点 | 最终场关闭申请后不再进入连续出击动作；连续场保持续战 |
| F3 库存误完成 | 每页零命中原位重试，仍失败即中止；要求底部滚动条与画面连续 3 轮稳定 | 中段停住、识别失败不再覆盖旧库存；无可靠滚动条的短列表或空列表暂时保守失败 |
| F4 羁绊旧记忆 | 键中加入实际本地库存 ID、目录指纹、COST 上限及优化器版本；区分本地有效库和实时回退；最长有效 24 小时 | 库存或业务数据变化触发重算；实时模式在有效期内仍不能自动获知所有新增持有对象 |
| F5 本机测试导入 | 开发配置保存在忽略的 `assets/interface.local.json`，正式配置移除仅本机存在的任务导入；增加发布导入检查 | 保留原来的开发入口副本，正式入口不再依赖被忽略的任务；本地副本需显式加载和维护 |
| 目录查询 | 按路径、修改时间和文件大小缓存从者目录及别名索引；返回深拷贝 | 重复查询免于反复解析，调用方修改不会污染缓存；保留目录冲突校验 |
| 测试交付 | 放行正式测试文件，继续忽略本机调试脚本；使用最小 BBC/Chaldea 样本替代个人目录；增加统一运行入口和 CI 两套作业 | 其他协作者能在不含 `BBchannel`、`config` 的源码副本中运行验证 |
| 校验覆盖 | 补导入片段 schema 和现有 MXU 字段；明确缺失 schema 失败；检查导入、循环与入口；统一 UTF-8 输出 | tasks/options 不再因缺 schema 被跳过后误报通过；CI 拒绝未跟踪导入 |

实现主要位于 `agent/custom`、`assets/resource/base/pipeline/原生自动战斗调度.json`、`tools/validate_schema.py`、`tools/run_tests.py` 和 `.github/workflows/check.yml`。本次变更包含修复、测试与文档，不涉及打包版同步。
