# BBC 配置转 Chaldea 本地队伍

在任务列表选择「BBC 配置转 Chaldea 本地队伍」，从 `BBchannel/settings` 选一个队伍 JSON 后运行。任务只处理本地文件，无需启动 BBC，也不会进入游戏。成功时日志会给出生成文件名；文件保存在 `config/Battle`，名称以 `bbc_` 开头。

随后在「芥雏子学姐在线代打」或「Chaldea 自动编队」的 Chaldea 队伍导入框中填写该文件名（也可选择该文件）。原生战斗会从同一份 JSON 读取技能、换人和宝具；自动编队读取前后排从者、助战和可确定的助战礼装。

转换按 BBC 从者资料里的 SN 确定从者 ID。普通技能、指定我方目标、御主技能、换人 `[12, 首发位, 候补位]`、每回合宝具顺序会转换。转换后的技能顺序按 BBC 配置执行，包括换人后继续施放的技能。相同源文件重复运行会复用生成结果；源文件修改后会生成带新哈希的文件名，不会覆盖旧队伍。

自定义选卡策略暂时跳过，由原生战斗的选卡逻辑补足面卡。日志和生成文件的 `_conversionWarnings` 会记录被跳过的策略。

以下内容没有等价的 Chaldea 固定回合表示，任务会报错且不生成文件：条件分支、BBC 扩展动作、波次额外技能、未知魔术礼装、无法识别的从者。BBC 扩展动作指 `roundN_turnM_skill` 中超出普通技能编号和标准换人的指令，例如 `["BBDubai", 3, 0]`、`["Prelati", 4, "替换"]`、`["Start", 1, [1]]`、`["End"]` 或负数编号；它们不是 Chaldea 战斗计划里的普通技能。条件分支指非空的 `roundN_turnM_condition`，其中可能包含 `cards: ["1B"]` 这样的卡牌条件；固定回合计划无法保存这些判断。

BBC 配置中的助战技能、宝具和从者等级筛选值会在有效时导入；未填写的筛选值保持不要求。`assistEquip` 只描述助战礼装，能唯一匹配本地 Chaldea 礼装 ID 时写入助战槽位。BBC 配置没有逐个指定自有从者概念礼装的字段，因此这些槽位不会生成 `equip1`，当前自动编队会跳过它们的礼装配置；需要按实际打法手动核对。`dropImage` 是掉落识别图片路径，不是队伍礼装。自有从者的等级和技能等级也没有完整来源，转换器不会臆造。

生成的 `team.mysticCode.mysticCodeId` 会供战斗计划识别御主技能和换人；当前 Chaldea 自动编队不会在游戏里切换魔术礼装。使用含御主技能或换人的攻略前，需要确认游戏当前魔术礼装与 JSON 一致。

原生战斗计划按整场战斗的回合序号推进；若实际清波所需回合数与 BBC 配置不同，后续技能会错位。首次使用转换结果时建议观察一场实战。
